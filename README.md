## What I Build

### System Modernization

使用 C#／ASP.NET Core、Vue 與 Flutter，逐步把舊系統整理成可維護的 Web、API 與 App。我重視既有契約、資料正確性、權限邊界與階段性移轉。

### AI-Assisted Engineering

把 AI 放進規格、實作、測試與 Review 流程。保存 Prompt、Diff、測試結果與人工決策，讓開發過程可以驗證與重播。

### Open Source & Writing

把真實問題整理成開源工具、可執行 Demo、文件與技術文章，讓讀者能直接使用，也能理解背後的工程取捨。
